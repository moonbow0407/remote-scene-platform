# 验收基线与测试夹具（Stage 0）

> 存放位置：本文档现位于 Python 实现仓库 `remote-scene-platform/doc/`。夹具文件在本仓库 `tests/fixtures/`。
>
> 状态：Stage 0 交付物。首版迁移以人工端到端场景为主要验收方式；本文给出测试夹具清单、每个夹具的预期可观察结果，以及按阶段拆分的人工验收脚本。
>
> 使用方式：每个阶段的验收按对应脚本执行，全部步骤使用稳定标识与预期计数断言，不依赖视觉判断。执行结果记录在阶段完成说明中。

## 1. 测试夹具清单

夹具必须足够小（全部 < 10 MB），但保留真实 CRS、波段与几何元数据，存放在新仓库 `tests/fixtures/` 下并入库。所有栅格夹具内容为合成数据（程序化生成），不使用任何带版权或涉密的真实影像。

| # | 夹具 | 文件 | 规格要求 | 主要用途 |
| --- | --- | --- | --- | --- |
| X1 | 多波段 GeoTIFF | `multiband.tif` | 4 波段 Byte，512×512，EPSG:32650（UTM 50N），带 GeoTransform，波段 1–3 有有效纹理、波段 4 近似常值 | 栅格主链路：COG 转换（保留源 CRS）、EPSG:4326 footprint、默认 RGB 渲染推断、瓦片读取 |
| X2 | 单波段 GeoTIFF | `singleband.tif` | 1 波段 UInt16，256×256，EPSG:4326，有效 min/max 差异 | 单波段默认灰度渲染推断；EPSG:4326 源的"同 CRS 不重投影"路径 |
| X3 | 缺失 CRS 栅格 | `no_crs.tif` | 3 波段 Byte，128×128，无 CRS、无 GeoTransform | `NEEDS_INPUT` 纠错链路：补充 CRS 后断点恢复 |
| X4 | GeoJSON | `points.geojson` | EPSG:4326，50 个 Point 要素，属性含字符串/数值/null 三类 | 矢量导入、JSONB 属性、要素空间查询 |
| X5 | 打包 Shapefile | `polygons_shp.zip` | `.shp/.shx/.dbf/.prj` 齐全，EPSG:4326，20 个 Polygon | 矢量压缩包检测、原文件保留、要素导入 |
| X6 | GeoPackage | `lines.gpkg` | EPSG:3857（验证 CRS 归一化），30 个 LineString，10 个属性列 | 矢量导入、CRS 归一化到 4326、属性结构记录 |
| X7 | 普通附件 | `report.pdf` | 数百 KB 合法 PDF | 附件资产：不触发地理处理、签名下载 |

派生期望值（入库后必须断言）：

- X1：`raster_asset_version` 记录 width=512、height=512、bands=4、crs=EPSG:32650；footprint 顶点落在 50N 带对应经度范围（约 114°E–115.5°E）；COG 对象存在且含 overview；渲染推断为 RGB(1,2,3)。
- X2：渲染推断为灰度(1)；CRS 为 EPSG:4326，footprint 与源 bbox 一致。
- X3：Job 进入 `NEEDS_INPUT`，诊断含"缺少 CRS"；提交 CRS=EPSG:4326 后从阻塞步骤恢复，不再要求重新上传。
- X4：要素数=50；几何类型 Point；属性 Schema 记录 3 类。
- X5：要素数=20；原文件（zip）在 MinIO 可签名下载。
- X6：要素数=30；导入后几何归一化为 EPSG:4326（extent 换算到经纬度）；属性结构 10 列。
- X7：状态 `READY`，无任何 COG/footprint/要素产出。

## 3. 验收判定原则

- 断言对象是 API 响应、数据库业务状态、对象存储内容与可观察结果，不断言内部方法调用次数。
- 涉及时间（恢复期、RRULE、重试）的步骤使用可控时钟，不靠真实等待。
- 每次验收在干净环境重放，不依赖上次遗留状态。
- 集成测试覆盖：Alembic 于真实 PostgreSQL/PostGIS、几何与 CRS 归一化、MinIO Multipart、RabbitMQ/Celery 投递与重投、Outbox 并发认领与陈旧认领恢复、TiTiler 私有对象读取与瓦片网关令牌、Scheduler 锁与唯一发生、矢量导入事务回滚。
- 单元测试仅覆盖：状态转换、重试分类、RRULE/固定间隔边界、增量窗口、GeoJSON 校验、渲染推断、引用清理决策。
