# 前端接入指南（Stage 7）

## 1. 契约入口

- OpenAPI：`GET http://localhost:8080/api/v1/openapi.json`；交互文档：`/api/v1/docs`。
  两者与业务 API 一样经 Nginx 提供，不暴露内部 API 容器地址。
- 业务路径全部位于 `/api/v1`。成功响应无全局信封；分页固定为
  `items/total/page/page_size`；错误媒体类型为 `application/problem+json`。
- 所有时间必须携带时区；空间输入使用 `spatial_geojson`，只接受 EPSG:4326 GeoJSON Polygon/MultiPolygon。

## 2. Multipart 上传

1. `POST /api/v1/uploads/sessions` 提交资产类型、文件名、总字节数、分片数和业务元数据。
2. 使用返回的预签名 URL 直接 `PUT` 各分片到 MinIO；文件字节不经过 FastAPI。
3. 中断后 `GET /sessions/{id}` 查看已传分片，缺失 URL 用
   `GET /sessions/{id}/parts/{part_number}/url` 补签。
4. `POST /sessions/{id}/complete` 返回资产版本与 Job；重复完成幂等返回同一结果。
5. 轮询 `GET /jobs/{job_id}`。`NEEDS_INPUT` 时读取诊断，并向
   `/assets/{asset_id}/versions/{version_id}/inputs` 补充 CRS。

大文件分片必须遵守 S3 Multipart 限制；客户端不要把文件先读入一个内存缓冲区。

## 3. 下载与瓦片

- 原件/工件：请求版本的 `artifacts/{kind}/download-url`，再在有效期内访问短期 URL。
- 栅格瓦片：请求 `tile-url` 得到经 Nginx `/tiles/` 的模板；不要拼 TiTiler 或 MinIO 内网地址。
- 无令牌、篡改令牌和过期令牌均按失败处理；客户端应重新申请，不缓存为永久 URL。

## 4. 生命周期与任务取消

- 删除资产调用 `DELETE /api/v1/assets/{id}`；普通详情和检索会立即隐藏它。
- 恢复期内调用 `POST /api/v1/assets/{id}/restore`；过期返回
  `ASSET_RESTORE_WINDOW_EXPIRED`。
- `POST /api/v1/jobs/{job_id}/cancel`：排队任务立即取消；运行任务返回
  `CANCEL_REQUESTED`，随后在处理步骤检查点进入 `CANCELLED`。

前端应以 Job 资源为状态权威，不以 RabbitMQ 或 HTTP 请求持续时间推断处理结果。
